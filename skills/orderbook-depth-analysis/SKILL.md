# Orderbook Depth Analysis

## Overview
This skill examines real-time order books, computing market depth, liquidity profiles, and execution slippage across price levels.

## Capabilities
- Computes effective bid-ask spreads and liquidity density across token tiers.
- Models price impact and expected execution slippage for specified trade sizes.
- Identifies iceberg orders and liquidity gaps in thinly traded outcome books.
